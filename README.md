# CONTENT TRANSFORMATION RULE

Do not simply paste the TreeQ Power document into generic templates.

Instead:

1. Understand the TreeQ Power content.

2. Categorize it according to the TreeQ Power IA.

3. Identify the purpose of each page.

4. Rewrite/format content where necessary for web readability.

5. Present the content using premium layouts inspired by the reference website.

6. Maintain technical accuracy.

7. Do not invent unsupported claims.

8. Do not remove important technical information simply to make the page shorter.

9. Break long technical content into visually digestible sections.

10. Use interactive storytelling where it improves comprehension.

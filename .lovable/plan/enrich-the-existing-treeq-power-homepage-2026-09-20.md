# Enrich the existing TreeQ Power homepage

## Goal
Expand only the homepage content below the existing hero into a premium B2B engineering experience. Preserve the hero, shared header/footer, colors, typography, motion system, navigation, responsive behavior, and all existing internal pages.

## Non-negotiable preservation
- Keep the existing hero markup, words, image, overlay, buttons, links, spacing, and animation unchanged.
- Keep the approved current route hierarchy. Where the brief supplies legacy `/our-services/...` URLs, link to the equivalent live `/services/...` routes rather than introducing duplicate pages.
- Use only factual supplied content. Keep projects as explicit placeholders and do not add client names, statistics, testimonials, certificates, reviews, or performance claims.

## Homepage content below the hero
- Add a compact linked capability strip for eight disciplines.
- Add an About TreeQ Power split section with lifecycle-focused copy and a real industrial engineering photograph.
- Build an eight-card core capability grid using the current icon-led visual language and relevant internal links.
- Add six numbered reasons to work with TreeQ Power, paired with real field-engineering imagery.
- Add comprehensive service and solution previews with concise technical summaries and direct links to the corresponding existing pages.
- Add five industry cards with distinct real photographs for Oil & Gas, Industrial, Commercial, Infrastructure, and Utilities.
- Add a six-step delivery approach and an interactive linked technical-solutions section.
- Add dedicated Asset Integrity and Sustainability split features with separate real photographs.
- Add a project-preview structure using clearly labelled image placeholders only.
- Add Resources cards, a six-question accessible FAQ accordion, and a strong two-action final contact section.
- Keep contact details consistent with the existing site; do not add a new or unverified form integration.

## Photography and performance
- Reuse appropriate existing locally managed Unsplash assets where they are semantically accurate.
- Add a cohesive set of properly licensed Unsplash photographs for missing subjects, including switchgear, automation, inspection, HVAC, solar, oil and gas, commercial buildings, infrastructure, and utilities.
- Store images through the project asset flow, use descriptive filenames and alt text, define stable aspect ratios, and lazy-load all below-the-fold imagery.
- Use approximately 15–20 meaningful placements without presenting stock imagery as TreeQ project work.

## SEO and structured data
- Update the homepage title, description, Open Graph title/description, Twitter card, and canonical URL.
- Use the existing real industrial hero image as the social preview only if an absolute hosted URL is available; otherwise omit image metadata rather than publishing a relative URL.
- Keep exactly one H1 in the untouched hero and organize the new content with logical H2/H3 headings.
- Add factual Organization, LocalBusiness, WebSite, and FAQPage JSON-LD. Do not add ratings, reviews, awards, unverified email addresses, or unsupported claims.

## Visual and interaction treatment
- Extend the current TreeQ/Zoho-inspired editorial system rather than redesigning it.
- Reuse current section reveal animations and add restrained hover/focus interactions to linked cards and technical selectors.
- Maintain semantic markup, keyboard access, visible focus states, reduced-motion behavior, and mobile layouts without horizontal overflow.

## Verification
- Compare the hero before and after to confirm it is unchanged.
- Validate one H1, heading order, all internal links, accordion keyboard behavior, image loading/alt text/lazy loading, and metadata/JSON-LD.
- Test desktop and mobile layouts, scroll reveals, overflow, console errors, and current build health.

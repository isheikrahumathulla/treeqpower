# TreeQ Power multi-page website

## Goal
Convert the current long homepage into a complete multi-page corporate website. Every item in the approved Source 3 hierarchy will have its own URL, while Source 2 will supply the factual content and the current premium TreeQ visual system will remain consistent across the site.

## Shared site structure
- Move the header, desktop mega menus, mobile navigation, enquiry call-to-action, and footer into a shared site layout.
- Replace all homepage scroll links with real page navigation.
- Keep the homepage focused on a concise overview with links into the detailed pages.
- Use the approved TreeQ green, orange, black, Sora, and Manrope visual system across all pages.
- Use a cohesive set of locally managed HD Unsplash images for engineering, field service, testing, sustainability, power infrastructure, and industrial contexts.

## Page design and content
- Create reusable page patterns for section overview pages and detailed service/solution pages so the site feels consistent rather than duplicated.
- Improve Source 2 wording for clarity, grammar, hierarchy, and professional B2B tone without changing technical meaning.
- Use strong page-specific opening imagery, concise introductions, scannable technical scope blocks, related-page navigation, and clear enquiry actions.
- Keep certifications, client/partner logos, testimonials, project records, case studies, and downloads as explicit placeholders until approved material is supplied.
- Exclude generic residential-electrician copy, fake statistics, duplicate testimonials, irrelevant blog posts, garbled pricing, and copied third-party material.
- Present Asset Integrity content conservatively using only generic methodology and clearly mark unsupported specifics for client review.

## SEO and quality
- Give every route a unique title, description, Open Graph title/description, canonical URL, and route-specific URL metadata.
- Ensure every menu and related-content link resolves to a real page.
- Verify desktop and mobile navigation, page rendering, image loading, keyboard access, responsive layout, overflow, and build health.

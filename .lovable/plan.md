# Remove Projects content sitewide

## Scope
- Remove Projects from desktop navigation, mobile navigation, and footer links.
- Remove the homepage Project Experience / Our Projects section and its placeholder cards.
- Remove Projects links from page-level related navigation and calls to action.
- Remove the dedicated Projects, Project Portfolio, and Case Studies page records so those URLs no longer publish placeholder content.
- Remove CSS and icon imports used only by deleted Projects sections.

## Preservation
- Keep the shared design, animation, responsive behavior, and all non-Projects pages unchanged.
- Keep ordinary operational wording such as “project requirements” where it describes how engineering services are delivered; this is not portfolio or Projects-page content.

## Verification
- Search the rendered source for Projects navigation, sections, placeholders, and `/projects` links.
- Check desktop and mobile navigation, homepage layout, removed URLs, console output, and build health.
